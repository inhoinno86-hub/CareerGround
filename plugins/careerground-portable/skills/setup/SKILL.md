# CareerGround 시작과 자료 선택

## 프로젝트 권고와 기준 자료 선택 — 0.2.0

프로젝트는 경력·근거 재사용, 기본/맞춤 이력서와 history 관리, 새 대화 재개,
면접 전달 버전 관리를 돕는 권장 작업 공간이다. 경력 작업의 필수 조건은 아니다.
사용자가 프로젝트를 거절하거나 밖·불명·미지원·이동 실패이면 현재 대화와 선택 파일로 계속한다.
이 상태를 준비 완료나 소속 인증으로 바꾸지 않고, 준비 확인을 반복하거나 작업을 차단하지 않는다.

현재 접근 가능한 기준 JSON의 workspace/profile ID·버전 또는 초기 작성 선택은 확인한다.
파일 없음은 초기 작성 선택, 복수 기준본·다른 프로필·충돌은 사용자 선택을 받는다.
같은 대화에서 이미 선택한 자료는 재사용하고 새 대화에서는 다시 선택한다.
파일 접근 실패를 기억으로 채우거나 선택하지 않은 자료를 병합하지 않는다.
[공통 시작 규칙](references/workflow.md)을 적용한다.

프로젝트 사용 여부는 사실 확인·사용 허용·사용 금지의 변경 승인이 아니다.
역할·기간·수치·공동 기여·원문·출처와 정확한 문구 검토 기준을 그대로 유지한다.
선택 자료의 생성·검사·다운로드·선택적 프로젝트 등록·앱 전달은 별도 상태다.

지원 파일 경로는 이 SKILL.md의 디렉터리 기준이다. skills.read에는 이 스킬 안의 상대 경로를 쓴다.
[공통 시작 규칙](references/workflow.md)을 읽는다.
첫 안내에는 사용자의 언어로 네 가지 이유를 설명한다.

> 프로젝트를 사용하면 확인한 경력과 근거를 여러 JD에 재사용하고, 기본/맞춤 이력서와
> history를 함께 관리하며, 새 대화에서 기준 자료로 이어가고, 면접 전달 자료의 버전을
> 맞추기 쉽습니다. 프로젝트 사용은 권장 사항이며 현재 대화에서도 선택 자료로 작업할 수 있습니다.

사용자가 원하면 실제 사용자 UI로 준비하는 방법과 [프로젝트 지침](templates/project-instructions.md)을 제공한다.
UI를 보지 못하면 구체적 메뉴·URL을 만들지 않는다. 프로젝트 생성·이동·저장을 대신 완료했다고 말하지 않는다.
프로젝트를 거절했거나 사용할 수 없다면 그 선택을 존중하고 현재 대화에서 진행한다.
이미 설명한 권고를 반복하거나 프로젝트 준비를 요구하지 않는다.
기준 파일이 없으면 초기 작성을 선택받고, 있는 파일은 ID/버전을 보여 선택받는다.
이 선택은 사실 확인이나 이력서/면접 사용 허용을 대신하지 않는다.
