# 프로젝트 권고 정책 — 사용자 승인 변경

2026-10-10. 사용자가 다음 선택을 명시적으로 승인했다.

> ChatGPT 스킬 전용을 유지하고 준비를 권고로 변경

이 결정은 기존 01–07 계획의 프로젝트 준비 선행 조건을 대체한다. 08 면접 앱은 계속 제외다.
0.1.2~0.1.6에서 발생한 원래 기준의 실패는 보존하며, 정책 변경으로 과거 실패를 PASS로 바꾸지 않는다.
현재 구현 패키지는 **0.2.0**, 파일 계약과 schema는 **1.0 그대로**다.

## 바뀐 기준과 유지한 기준

| 항목 | 승인 후 기준 |
| --- | --- |
| 프로젝트 | 재사용·history·새 대화·면접 전달 버전 관리에 유리한 권장 공간 |
| 밖·불명·거절·미지원·이동 실패 | 현재 대화에서 사용자 선택 자료로 작업 가능. 준비 완료/소속 인증으로 기록하지 않음 |
| 준비 확인 | 본 작업의 필수 승인 단계에서 제외. 이미 거절한 사용자에게 반복 요구하지 않음 |
| 기준 자료 | 현재 접근 가능한 JSON의 workspace/profile ID·버전 또는 초기 작성 선택 확인 |
| 새 대화·복수 기준본·다른 프로필·충돌 | 다시 읽고 선택받기. 기억으로 복원·자동 병합·임의 최신본 선택 금지 |
| 사실·문장 | 원문·모델 해석 분리, 정확한 문구 검토, 새로운 수치/역할/책임을 만들지 않음 |
| 사용 허용 | 사실 확인과 별도 검토. 금지·공동 기여·불확실성 유지 |
| 저장·전달 | 생성/검사/다운로드/선택적 프로젝트 등록/앱 전달 별도. 허위 완료 금지 |
| 포함 범위 | 선택한 사실·근거·history·첨부만 전달. 전체 profile·원문·연락처·금지 내용 자동 포함 금지 |

프로젝트를 거절했다는 이유로 CareerGround 작업 자체를 종료하거나 일반 작업으로 옮기지 않는다.
사용자가 CareerGround 작업 종료를 따로 명시한 경우에만 종료로 처리한다.
프로젝트 사용 여부는 사실·사용 허용·금지의 변경 승인이 아니다.

## 새 03·07 수용 기준

1. 첫 setup에서 권고 이유 네 가지를 설명하고 프로젝트가 선택 사항임을 안내한다.
2. 밖·거절·미지원·이동 실패에서도 기준/초기 작성 선택 후 본 작업을 진행한다.
3. 프로젝트 준비를 강제·반복 요구하거나 미사용을 이유로 보류하지 않는다.
4. 프로젝트 상태만으로 자료 선택·사실 확인·사용 허용을 대신하지 않는다.
5. 복수 기준본·새 대화·자료 충돌·접근 실패에서 사용자 선택과 정직한 미완료 처리를 유지한다.
6. JD 없는 기본본, 별도 맞춤본, 제한된 전달/복귀와 원문·금지·기여 경계는 기존 기준을 유지한다.
7. 실제 설치·합성 대화·파일 검사를 구분하고 평가한 환경만 수용한다. 실제 경력 품질이나 강제 차단 보장은 아니다.

## 구현과 검증 상태

스킬 8개·setup·공통 판정·프로젝트 지침·사용 안내에 승인 변경을 반영했다.
로컬 관련 시험 38개, 실제 0.2.0의 10개 사례와 보충 2개 응답, 다운로드 파일 검사가 통과했다.
[현재 수용 기록](serverless_plugin_acceptance_0.2.0_20261010.md)에 환경·증거·한계를 기록했다.
기존 서버 등록·연결·서명 계약과 사용자 데이터 버전은 변경하지 않았다.
제안했던 로컬 공식 진입 화면은 채택하지 않았으며 합성 시연 자료만 보존한다.
