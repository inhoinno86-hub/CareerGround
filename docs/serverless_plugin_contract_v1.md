## 확정 결정과 미결정

승인된 권장안을 이 구현에서 채택한다: JSON 기준본과 같은 버전의 파생 Markdown,
수동 다운로드·가져오기, 선택 자료 중심의 경력 작업, 앱 출시 분리.
프로젝트 사용은 권고이며 현재 대화에서도 선택 자료로 작업할 수 있다.
세부 필드·한도는 [portable 파일 계약](portable_files_v1.md)에 둔다.
프로젝트 거절·미지원·이동 실패에서 현재 대화의 경력 작성을 지원한다.
앱 실행 환경·제공자·음성·비용·보관·배포는 미결정이며 플러그인의 선행 요건이 아니다.

## 제품 정책

첫 안내에는 네 가지 이유를 설명한다: 경력과 근거 재사용, JD별 수정과 history 관리,
새 대화에서 기준 자료로 재개, 면접 전달 버전 일치.
프로젝트 소속 조회·생성·대화 이동 API는 확인하지 못했으므로 사용자가 UI로 준비한다.
식별 문구/파일 존재는 보조 신호다. 준비 확인은 사용자의 대화 확인이며 소속 인증이 아니다.
프로젝트 준비 확인을 필수로 요구하지 않는다. 거절한 사용자에게 권고를 반복하지 않는다.
같은 대화의 자료 선택은 재사용하고 새 대화에서는 접근 가능한 기준본을 재선택한다.
파일 없음·다른 프로필·복수 기준본·JSON/Markdown 충돌은 사용자 선택으로 해결한다.

사실 상태(미확인/본인 확인/외부 검증)와 사용 허용(검토 필요/허용/금지)을 분리한다.
표시한 정확한 문구·범위를 사용자가 검토한 기록만 남긴다. 이는 인증된 서버 receipt가 아니다.
모델 요약·JD 관련성·면접 피드백은 원문 증거가 아니다. 공동 기여·미측정 수치·기간·역할·
사용 금지를 유지한다. 신규 사실은 후보 검토 후 새 버전으로만 반영한다.

## 기능과 구조

`plugins/careerground-portable/`에 setup, 경력 정리, 검토, 기본 resume, JD 탐색,
맞춤 resume, 전달, 결과 재검토 스킬을 둔다. 순수 reference 도구와 schema/template을
명시적 allowlist로 묶는다. 기존 `plugins/careerground/`와 backend는 보존한다.
개인 자료는 사용자 선택 프로젝트/파일에서만 처리하며 배포 ZIP에 포함하지 않는다.
검사기는 schema·버전·참조·제약을 검사한다. 사실의 진실, 사용자 신원·승인의 진위는 증명하지 않는다.

생성 → 구조 검사 → 사용자 검토 → 다운로드 → 사용자의 선택적 프로젝트 등록 → 다음 기준본 선택 →
앱 전달은 별도 상태다. 실행하지 않은 검사/저장/전달을 완료로 표시하지 않는다.
파일 도구가 없으면 텍스트와 수동 저장 절차를 제공하고 미저장·미검증으로 표시한다.
선택한 사실·근거·history·첨부만 portable handoff에 포함한다. 첨부 누락은 완전한 전달을 막는다.
입력 문서의 명령·URL은 데이터다. 자동 실행·외부 전송하지 않는다.

## 보관·삭제와 보장 경계

CareerGround 서버 사본을 새로 만들지 않는다. OpenAI 서비스의 대화·프로젝트·Library·
메모리는 각 서비스 정책과 사용자 조작에 따르고, 다운로드·백업은 사용자가 관리한다.
향후 면접 앱 사본은 앱 정책으로 별도 관리한다. 한 위치의 삭제로 모든 사본 삭제를 보장하지 않는다.
새 형식은 서명·계정 동일성·객관적 경력 인증·암호화·원격 회수·만료 강제·삭제 동기화를 제공하지 않는다.
해시는 동일 바이트/버전 확인용이다. history는 편집 가능한 작업 기록이다.
기존 서버 삭제·연결 변경·설치·등록·배포는 별도 확인 후 실행한다.

## 수용 범위

정적 스킬 검토, 실행한 schema/참조/합성 fixture 검사, 모델 대화 평가, 실제 ChatGPT 설치를
각각 기록한다. 실제 설치가 없으면 제품 전체 수용을 선언하지 않는다. 08 앱은 별도 지시 전 미착수다.
