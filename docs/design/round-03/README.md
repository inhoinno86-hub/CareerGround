# Round 03 — 모듈 구성 × 차분한 녹색 × 정돈된 여백

사용자 피드백: 이전 03의 전체 구성, 04의 톤, 05의 깔끔함을 선호.
이전 02는 상투적, 01은 올드하게 느낌. 장식적 음성 구체, 광학 링, 세리프,
기울어진 종이 오브젝트는 이번 방향에서 제외한다.

## 제작 전 설계

- 공통 토큰: Mist `#f3f6f1`, White `#ffffff`, Forest `#264c41`, Sage `#e2ebdc`,
  Graphite `#243b32`, Peach `#f4ddcb`. Peach는 준비 도움말에만 절제해 사용.
- 한국어 제목/본문: Noto Sans CJK KR, 32/26/16/13px. 라틴 브랜드와 수치:
  Noto Sans Display. 실제 기기에서 쓸 글꼴은 Compose 구현 단계에서 확인한다.
- 기능 상태는 동일: 서비스 운영 직무, 검토한 자료 3개, 한 질문/한 회차,
  질문 1/5, 수정 가능한 초안, 명시적 사실 확인 후 제출. 실적·스트릭·점수 없음.
- 재검토: 카드만 반복하면 일반 대시보드가 된다. 3종 이상을 같은 bento로
  만들지 않고, 자료 준비와 답변 연습이라는 구체적인 관계를 구조로 표현한다.

| 안 | 배치 | 기억할 요소 | 면접 화면 |
| --- | --- | --- | --- |
| 01 SAGE | `[직무 2 : 자료 1] / [짧게 : 회차]` | 원래 선호한 비대칭 모듈을 정돈 | 질문·근거·답변의 독립 블록 |
| 02 FRAME | `제목 / [직무 + 자료 + 연습 선택] / 시작` | 준비 내용을 한 장의 패널 안에 묶음 | 질문부터 초안까지 한 장의 편집 패널 |
| 03 PACE | `직무 / 세로 준비 레일 / 두 개의 넓은 연습 행` | 실제 준비 단계와 열린 행 구조 | 세로 진행 레일 옆 질문, 아래 열린 답변 |
| 04 FIELD | `큰 제목 / 자료 요약선 / 여백 / 두 연습 모듈` | 카드 수를 줄이고 행동에 면적 할당 | 배경 위 큰 질문 + 낮은 답변 패널 |
| 05 LAYER | `[녹색 직무 헤더 + 자료] / 선택 행 / 시작` | 대비 있는 상단 영역과 밝은 조작 영역 | 녹색 질문 영역 + 밝은 답변 영역 |

`index.html`은 선택용 HTML 시안이다. 개별 안에는 시작/면접 화면과 밝기 전환이 있다.
기존 Compose APK는 1차 시안이며 이 라운드를 표현하지 않는다. 방향 선택 후 구현한다.
외부 리소스, 로그인, 마이크, AI, 파일 저장 없이 로컬 합성 상태만 사용한다.

## 검증

`render_studies.py`는 독립 headless Chrome으로 비교판/개별 PNG를 생성하고
밝은/어두운 테마, 모바일 너비, 주요 컨트롤 위치, 확인 체크의 조작을 검사한다.
결과는 `validation.json`에 기록한다. Android 렌더링과 기기 시험을 대신하지 않는다.
