# 프로젝트 권고와 작업 재개 1.1

2026-10-10. [사용자 승인 변경](serverless_project_recommendation_decision_20261010.md)에 따라
프로젝트 사용을 권고로 전환했다. 파일 schema는 1.0을 유지한다.
[setup](../plugins/careerground-portable/skills/setup/SKILL.md),
[공통 규칙](../plugins/careerground-portable/references/workflow.md),
[선택적 프로젝트 지침](../plugins/careerground-portable/templates/project-instructions.md).

첫 setup은 경력/근거 재사용, 기본/맞춤 이력서와 history 관리, 새 대화 재개,
면접 전달 버전 일치의 네 가지 이유를 설명한다. 프로젝트는 선택 사항이다.
밖·불명·거절·미지원·이동 실패에서도 현재 대화와 사용자 선택 파일로 작업할 수 있다.
거절한 사용자에게 준비 확인을 반복하거나 프로젝트 미사용만으로 작업을 중단하지 않는다.

| 상황 | 동작 |
| --- | --- |
| 프로젝트 사용 | 사용자 UI로 준비하면 좋은 이유·방법 안내; 소속 인증/자동 생성/이동 미보장 |
| 밖·불명 | 권고 안내 후 현재 대화에서 선택 자료로 시작 |
| 거절·미지원·이동 실패 | 선택 존중, 현재 대화에서 진행; 새 대화용 요약·자료 보관 방법 제공 |
| 파일 없음 | 초기 작성 선택 후 경험 질문 |
| 현재 파일 있음 | workspace/profile ID·버전 선택 후 작업 |
| 다른 프로필·복수 기준본 | 목록과 ID/버전으로 사용자 선택; 자동 병합 금지 |
| 새 대화·파일 접근 실패 | 현재 자료를 다시 읽고 선택; 기억으로 복원하거나 허위 읽기 금지 |
| JSON/검토 문서 충돌 | REVIEW_CONFLICT; 정확한 변경 후보를 별도 검토 |

같은 대화에서 선택한 자료를 불필요하게 다시 선택하게 하지 않는다.
프로젝트 준비는 자료 선택·사실 확인·사용 허용을 대신하지 않는다.
생성·검사·다운로드·선택적 프로젝트 등록·앱 전달은 서로 다른 상태다.
프로젝트를 쓰지 않는 경우 다운로드 사본과 다음 대화의 기준 자료를 사용자가 관리한다.

## 이전 정책 기록

강제 준비 정책은 [실패 재시험](serverless_plugin_failure_retest_20261010.md)과
[반복 보완·원인 분석](serverless_preparation_gate_remediation_20261010.md)에 보존했다.
원래 기준의 실패를 소급하여 통과로 바꾸지 않는다. 새 기준의 실제 평가는 별도로 기록한다.
