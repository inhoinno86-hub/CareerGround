# Exact R1 resume wording foundation (synthetic only)

Migration `20260927_0012` adds `artifact_wording_reviews` and `WORDING_REVIEWED` states for a resume artifact and its units. The internal `WordingReviewService` prepares one ten-minute HMAC review over the fixed artifact version, exact R1 unit text, Claim links, selected supporting Evidence excerpts and source references. Its submit path requires a matching `VerifiedWordingApproval` intended for a future trusted user-confirmation adapter. It atomically records one review and marks all units reviewed; replay is idempotent. It does not change the Career Graph or profile version.

Only R1 units copied exactly from eligible Claims can enter this path. R2 and R3 wording remain blocked because semantic changes and new facts need separate review. `export_resume` returns JSON or Markdown text in memory after checking the active owner, exact current profile version, reviewed journal/digest, JD mapping, Claim text, supporting Evidence, contradiction and active use boundaries again. It does not send content to an employer. A changed source version, missing link, changed wording or unavailable Evidence blocks export.

Deletion preview, local purge and restore quarantine include the review journal. This foundation has no public MCP/web route, real approval issuer, persistent download artifact or operational service. It uses synthetic identities and content only.
