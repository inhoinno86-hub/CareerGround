# Exact R1 resume wording foundation (synthetic only)

Migration `20260927_0012` adds `artifact_wording_reviews` and `WORDING_REVIEWED` states for a resume artifact and its units. The internal `WordingReviewService` prepares one ten-minute HMAC review over the fixed artifact version, exact R1 unit text, Claim links, selected supporting Evidence excerpts and source references. Its submit path requires a matching `VerifiedWordingApproval` intended for a future trusted user-confirmation adapter. It atomically records one review and marks all units reviewed; replay is idempotent. It does not change the Career Graph or profile version.

Only R1 units copied exactly from eligible Claims can enter this path. R2 and R3 wording remain blocked because semantic changes and new facts need separate review. `export_resume` returns JSON or Markdown text in memory after checking the active owner, exact current profile version, reviewed journal/digest, JD mapping, Claim text, supporting Evidence, contradiction and active use boundaries again. It does not send content to an employer. A changed source version, missing link, changed wording or unavailable Evidence blocks export.

Deletion preview, local purge and restore quarantine include the review journal. This foundation has no public MCP/web route, real approval issuer, persistent download artifact or operational service. It uses synthetic identities and content only. PostgreSQL 17.11 `0012` upgrade, schema check, empty-database downgrade/re-upgrade and the complete 158-test suite passed without skips; all 33 product tables were empty after tests.

The isolated synthetic browser factory now presents each exact R1 unit with its Claim, selected Evidence excerpt and source reference. A three-minute signed form binds the active account, opaque browser session, artifact, review ID, exact digest and expiry. Only an explicit checkbox submits it. The domain service reconstructs and rechecks the displayed review in the write transaction; changed wording, another browser session, missing fields and R2 wording cannot be approved. Same-token retry returns the one existing review. After review, a separate five-minute JSON or Markdown download form binds account, browser session, artifact, format and content hash; the POST rechecks the current Graph and returns a no-store attachment. No employer transmission, public product route or real-user data is connected.
